# Appliance image · 設備映像

> A small Linux image that boots straight into the web app, for a VM or a spare PC.
>
> 一個細細嘅 Linux 映像，一開機就直入網頁程式，啱晒虛擬機器或者一部用唔着嘅電腦。

Category: [Ways to run it](README.md) · [Read on the website, with pictures](https://ding-ding-projects.github.io/map-editor/appliance/)

## What it is

An Alpine Linux image with Docker and the Map Editor image already inside. On boot it starts the web app and prints the address on the console, along with the note that the first person to open it becomes the owner.

一個 Alpine Linux 映像，入面已經有齊 Docker 同 Map Editor 映像。開機嗰陣佢會啟動網頁程式，喺主控台印出個地址，仲會提你第一個開佢嘅人會成為擁有人。

## Use it

Import map-editor-appliance-x86_64.ova into VirtualBox or VMware with a bridged network adapter, or write map-editor-appliance-x86_64.img to a USB drive and boot a spare PC from it. Map Editor Deploy does both for you.

將 map-editor-appliance-x86_64.ova 匯入 VirtualBox 或者 VMware，用橋接網絡介面卡；又或者將 map-editor-appliance-x86_64.img 寫入 USB 手指，再用佢嚟開一部用唔着嘅電腦。Map Editor Deploy 兩樣都可以幫你做。

## Tour of the appliance

The console has no login and needs no typing. It shows the version and the link to open, and a four-step guide: the link, opening it from another computer, creating the owner account on the first visit, and the ? button › Take a tour inside the editor, which walks through every screen. The console text refreshes when the network address changes.

個主控台唔使登入，亦都唔使打字。佢會顯示版本同要開嘅連結，仲有一個四步指南：條連結、喺另一部電腦度開佢、第一次去嗰陣建立擁有人帳戶，同埋編輯器入面嘅「? 按鈕 › 遊覽一次（Take a tour）」，佢會帶你行勻每個畫面。網絡地址一變，主控台啲字就會更新。

## How it is checked

Every build boots the image under QEMU and waits for the web app to answer its health check before the image is published.

每次建置都會喺 QEMU 底下開個映像，等到網頁程式回應健康檢查，先至會發佈個映像。

## Raspberry Pi

map-editor-appliance-rpi-arm64.img.xz is the same appliance for a Raspberry Pi 4 or 5. Unpack it and write the .img to an SD card (Map Editor Deploy › USB drive does this with a read-back check), then boot the Pi with a network cable. Every build checks its firmware, kernel and device trees and that the packed container is built for arm64. After each release it is booted on the QEMU Raspberry Pi 4 machine until the web app answers its health check. It has not yet been tested on a physical Pi. If the screen says the preloaded image is for another processor, download the image again from a newer release.

map-editor-appliance-rpi-arm64.img.xz 係同一個設備，畀 Raspberry Pi 4 或者 5 用。解壓之後將個 .img 寫入 SD 卡（「Map Editor Deploy › USB 手指（USB drive）」會幫你寫，仲會讀返出嚟核對），然後插住網絡線開部 Pi。每次建置都會檢查佢嘅韌體、核心同裝置樹，同埋入面包住嘅容器係咪為 arm64 而建。每次發佈之後，佢會喺 QEMU 嘅 Raspberry Pi 4 機器度開機，直到網頁程式回應健康檢查為止。佢仲未喺實體嘅 Pi 上面測試過。如果畫面話預載嘅映像係畀另一款處理器用，就去新啲嘅發佈度重新下載個映像。
