# Desktop app · 桌面程式

> A Windows app that opens worlds straight from your .minecraft saves folder.
>
> 一個 Windows 程式，可以直接喺你個 .minecraft saves 資料夾度開啟世界。

Category: [Ways to run it](README.md) · [Read on the website, with pictures](https://ding-ding-projects.github.io/map-editor/desktop-app/)

## Updates

The installed app looks for a newer version when it starts and every four hours, and downloads it in the background while you keep working. When it is ready, a banner names the version, links to its release notes and offers Restart to install update or Later. Nothing restarts on its own, and the restart waits if an edit is still running. Updates are not code-signed. About › Check for updates looks straight away. If the update site cannot be reached, the app you have keeps working.

裝好咗嘅程式會喺啟動嗰陣同埋每四個鐘睇吓有冇新版本，你繼續做嘢嘅時候佢會喺背景下載。準備好之後，會有條橫額講明係邊個版本、連去佢嘅發佈說明，仲有「重新啟動嚟安裝更新（Restart to install update）」同「遲啲先（Later）」畀你揀。佢唔會自己重新啟動，如果仲有編輯行緊，重新啟動都會等埋先。更新冇做程式碼簽署。「關於（About）› 檢查更新（Check for updates）」會即刻去睇。如果連唔到更新網站，你手上嗰個程式照樣用得。

## What it does

The desktop app runs the same editor as the web app, inside its own window. It starts a private server on your computer that only that window can reach, so nothing is exposed to your network.

桌面程式行嘅編輯器同網頁程式係同一個，只係放喺自己嘅視窗入面。佢會喺你部電腦度開一個私人伺服器，淨係得嗰個視窗連得到，所以唔會有嘢暴露喺你個網絡度。

## Install

Download Setup.exe from the latest release and run it. The installer is not code-signed, so Windows SmartScreen may show a warning first; choose More info, then Run anyway. Updates arrive through the same release feed.

喺最新嘅發佈度下載 Setup.exe 再執行佢。安裝程式冇做程式碼簽署，所以 Windows SmartScreen 可能會彈個警告出嚟先；揀「其他資訊（More info）」，跟住揀「仍要執行（Run anyway）」。更新都係經同一個發佈來源送到。

## Build it yourself

On Windows run build.bat --run from the repository. It installs Node.js and Git through Chocolatey if they are missing (one admin prompt), builds everything and starts the app.

喺 Windows 度，喺儲存庫入面執行 build.bat --run。如果冇裝 Node.js 同 Git，佢會用 Chocolatey 幫你裝（會問一次管理員權限），跟住建置晒所有嘢再啟動個程式。

## When something goes wrong

If the window stays blank, another copy may already be running: Map Editor allows one copy at a time. If a world does not appear, check that it is a Java Edition 1.18 or newer world with a level.dat file.

如果個視窗一直空白，可能係已經有另一個開緊：Map Editor 每次只可以開一個。如果有個世界冇出現，睇吓佢係咪 Java 版 1.18 或者更新嘅世界，同埋有冇 level.dat 檔案。
