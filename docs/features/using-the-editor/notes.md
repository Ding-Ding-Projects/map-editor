# World notes · 世界筆記

> Rich text notes for each world, saved automatically.
>
> 每個世界都有豐富文字筆記，會自動儲存。

Category: [Using the editor](README.md) · [Read on the website, with pictures](https://ding-ding-projects.github.io/map-editor/notes/)

## What it does

The Notes panel is a rich text editor (TinyMCE) for plans and coordinates. Notes belong to the open world and save about a second after you stop typing.

「筆記（Notes）」面板係一個豐富文字編輯器（TinyMCE），用嚟記低計劃同座標。筆記屬於開緊嗰個世界，你停手唔打字之後大約一秒就會儲存。

## Where they are kept

In the app data folder next to the world history, never inside the world itself.

喺程式資料夾入面，世界歷史隔籬，永遠唔會放喺世界本身裏面。
