# Getting worlds in and out · 世界點樣入嚟同出去

> Upload a world as a .zip, download it again, or start a new flat world.
>
> 將世界以 .zip 上載、再下載返，又或者開一個新嘅平坦世界。

Category: [Using the editor](README.md) · [Read on the website, with pictures](https://ding-ding-projects.github.io/map-editor/worlds/)

## Select several, and the bin

Select on the Worlds screen switches on tick boxes: click or tick, Shift+click for a range, Ctrl+A for all, Invert to swap. Download selected saves each ticked world in turn. Move to bin asks with the two-key confirmation, then moves the ticked worlds, whole, into a bin folder inside the worlds folder; nothing is deleted, the open world is left alone, and a line says what was not moved and why. Bin lists them with Put back. To free the space, remove them yourself from the bin folder.

世界頁嘅「揀選」會開剔格：撳或者剔，Shift 加撳揀一段，Ctrl+A 全選，「反轉揀選」調轉。「下載揀咗嘅」會逐個下載。「掉入回收筒」會先過雙重確認，跟住將剔咗嘅世界成個搬入世界資料夾入面嘅回收筒資料夾；唔會刪任何嘢，開緊嗰個世界唔會郁，仲會有一行講邊個冇搬到同原因。「回收筒」會列晒出嚟，有「放返出嚟」。想騰出空間，就自己去回收筒資料夾移除。

## Bedrock Edition worlds

Bedrock Edition worlds open like any other: upload a .mcworld file (or a .zip of the world folder) and download it again as .mcworld, ready for the game. The map, the side view, the 3D view, Pick block, Fill, Replace, Delete blocks and Clone all work, in the Overworld, the Nether and the End. Fill and Replace use blocks that are already somewhere in the world: choose one in the Blocks panel, which lists the blocks found in the world so far, pick one from the map with Pick block (I), or type minecraft:air. That way every block is written back exactly as the game wrote it. Biomes, waterlogging, structure files, mobs and the contents of chests are not changed in Bedrock worlds, and chunks the game has not made yet are never invented. Saving adds one new file to the world database and leaves the others alone, so History can take any edit back. Close the world in the game before editing it here, and keep a copy the first time you try it.

基岩版嘅世界同其他世界一樣開得：上載一個 .mcworld 檔案（或者世界資料夾嘅 .zip），再以 .mcworld 下載返，攞去遊戲度即刻用得。地圖、側面圖、3D 視圖、揀方塊（Pick block）、填充（Fill）、取代（Replace）、刪除方塊（Delete blocks）同複製（Clone）全部都用得，喺主世界（Overworld）、地獄（Nether）同終界（End）都得。填充同取代用嘅係世界入面某處已經有嘅方塊：喺「方塊（Blocks）」面板度揀一個，佢會列出到而家為止喺個世界度搵到嘅方塊；又或者用揀方塊（I）喺地圖度揀一個；又或者打 minecraft:air。噉樣每一個方塊寫返入去嗰陣，都同遊戲自己寫嘅一模一樣。喺基岩版世界入面，生態域、含水狀態、結構檔案、生物同箱入面嘅嘢都唔會改，而遊戲仲未生成嘅區塊亦永遠唔會憑空整出嚟。儲存嗰陣會喺世界資料庫度加一個新檔案，其他嘅唔會掂，所以「歷史（History）」可以將任何編輯收返。喺呢度編輯之前，要喺遊戲度閂咗個世界先，而第一次試嗰陣記住留返個副本。

## New worlds

New flat world asks for a name, a kind of world (Grass, Desert, Snow, Water, Stone bricks, or Void with one small stone platform under spawn) and a size from 64 to 384 blocks across.

「新平坦世界（New flat world）」會問你個名、世界嘅種類（草地 Grass、沙漠 Desert、雪地 Snow、水 Water、石磚 Stone bricks，或者虛空 Void，重生點下面有一個細細嘅石平台），同埋由 64 到 384 格方塊闊嘅大細。

## Upload a world

On the Worlds screen choose Upload world .zip and pick a .zip of a world folder from .minecraft/saves. Progress shows while it uploads. The server then checks every file path, looks for level.dat at the top of the archive or one folder down, and unpacks it into the worlds folder under a name that does not clash with an existing world. An archive without a world, or with a path that points outside its folder, is refused and nothing is kept.

喺「世界（Worlds）」畫面度揀「上載世界 .zip（Upload world .zip）」，再揀一個由 .minecraft/saves 入面嘅世界資料夾壓成嘅 .zip。上載嗰陣會顯示進度。之後伺服器會檢查每一條檔案路徑，喺壓縮檔嘅最頂層或者落一層資料夾度搵 level.dat，再將佢解壓去世界資料夾，用一個唔會同現有世界撞名嘅名。如果個壓縮檔入面冇世界，或者有路徑指去佢個資料夾外面，就會被拒絕，乜都唔會留低。

## When an upload finishes

A full-screen card says Ready to edit with the file, size and time taken, and Open in the editor. If the upload fails, a card stays until you dismiss it with the exact reason, Choose another and Copy details; nothing is kept. Settings › Comfort and focus › Full-screen result cards turns these off and keeps only the small messages.

會有張全螢幕卡片話「可以編輯喇（Ready to edit）」，連埋個檔案、大細同用咗幾耐，仲有「喺編輯器度開啟（Open in the editor）」。如果上載失敗，會有張卡片留喺度直到你閂咗佢，上面有確實嘅原因、「揀過另一個（Choose another）」同「複製詳情（Copy details）」；乜都唔會留低。「設定（Settings）› 舒適同專注（Comfort and focus）› 全螢幕結果卡片（Full-screen result cards）」可以閂咗呢啲卡片，淨係留返啲細訊息。

## Download a world

Download .zip on any world card streams the whole world back as a .zip with the world in its own folder, ready to drop into .minecraft/saves.

任何一張世界卡片上面嘅「下載 .zip（Download .zip）」，都會將成個世界以 .zip 串流返畀你，個世界放喺自己嘅資料夾入面，直接掉入 .minecraft/saves 就得。

## New flat world

New flat world makes an 8 by 8 chunk world of bedrock, dirt and grass with its spawn on the ground, for trying the tools.

「新平坦世界（New flat world）」會整一個 8 乘 8 區塊嘅世界，有基岩、泥土同草，重生點喺地面，用嚟試吓啲工具。

## Desktop app

The desktop app also has Browse folder… to open a world anywhere on your computer.

桌面程式仲有「瀏覽資料夾…（Browse folder…）」，可以開你部電腦任何位置嘅世界。
