# Postman collections

Status: **Partly built** · Section: Repository records and README · [All features](README.md)

## What is there

scripts/postman.mjs writes docs/postman/map-editor.postman_collection.json from the server's route list (54 requests in 7 area folders); each state-changing request carries the fields the server reads (`bodyFields`, taken from the server code) with a hand-written example per field, and uploads are file bodies with their required header; docs/postman/README.md; tests/server.test.ts fails when the collection, the route list or the field examples differ

## What is missing

separate collection per area (areas are folders inside the one master file); only five example bodies were sent to a running server (login, activity, op, extensions master, undo: all accepted); the rest were not
