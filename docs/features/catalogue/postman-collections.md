# Postman collections

Status: **Partly built** · Section: Repository records and README · [All features](README.md)

## What is there

scripts/postman.mjs writes docs/postman/map-editor.postman_collection.json from the server's route list (54 requests in 7 area folders); each state-changing request carries the fields the server reads (`bodyFields`, taken from the server code) with a hand-written example per field, and uploads are file bodies with their required header; docs/postman/README.md; tests/server.test.ts fails when the collection, the route list or the field examples differ | ; one collection file per area beside the master, checked by a test to hold every route exactly once | ; 12 example bodies sent in sequence to a running server and accepted (login, logout, activity, op, undo, extensions master, worlds new/open/bin/restore, history copy/restore)

## What is missing

the passkey, authenticator, local AI, upload and the other extension requests were not sent to a running server
