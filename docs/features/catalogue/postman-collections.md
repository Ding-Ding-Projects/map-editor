# Postman collections

Status: **Partly built** · Section: Repository records and README · [All features](README.md)

## What is there

scripts/postman.mjs writes docs/postman/map-editor.postman_collection.json from the server's route list (54 requests in 7 area folders); each state-changing request carries the fields the server reads (`bodyFields`, taken from the server code) with a hand-written example per field, and uploads are file bodies with their required header; docs/postman/README.md; tests/server.test.ts fails when the collection, the route list or the field examples differ | ; one collection file per area beside the master, checked by a test to hold every route exactly once | ; 12 example bodies sent in sequence to a running server and accepted (login, logout, activity, op, undo, extensions master, worlds new/open/bin/restore, history copy/restore); a second pass sent the rest: world upload, structure place, extension enable and run, passkey options and authenticator-free routes were accepted, and add-from-address, add-from-folder, remove built-in, passkey sign-in options and the local AI helper were refused with their own clear reasons, as they should be on this server; that pass caught and fixed a wrong selection shape in the extension run example; uploads carry the headers and address values the routes read

## What is missing

registering a passkey and confirming or turning off authenticator codes were not sent (they need a real authenticator)
